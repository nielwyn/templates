NARRA — Changelog
==================

v1.2.0 — 2026-11-08
--------------------
Initial release.

- Ten-section editorial sales page: hero, core tension, 4-pillar method,
  interactive 12-week curriculum tabs, deliverables vault, audio preview,
  three case studies, mentor story, tiered pricing with payment toggle, and
  an FAQ accordion — plus sticky nav, footer and a 3-step application drawer.
- Four colorway presets (Linen & Cedar, Tuscan Olive & Clay, Obsidian & Gold,
  Terracotta Silk) as [data-theme] blocks in src/index.css, previewable from
  the floating colorway switcher.
- Design tokens in :root — colors, radii, shadows, container width and fonts
  are all one-place edits.
- Ships as a prebuilt page in dist/ (open index.html, works offline) plus the
  React + TypeScript + Vite + Tailwind 4 source in source/. Lockfile included.
- Verified from a clean extract on Node v24.14.1: npm install, npm run build
  and npx tsc --noEmit all exit 0, no flags.
- WebP imagery, 424KB total; semantic HTML, alt text, WCAG AA contrast.
- Demo-only: the audio player has no <audio> element and the application
  drawer transmits nothing. Both are documented with the code to connect them.
