HALO — Branding & Web Studio Template
=======================================

Thanks for picking up this template!

QUICK START
-----------
1. Unzip this folder.
2. Open index.html in any web browser to preview the site (you'll need
   an internet connection — fonts, GSAP and Three.js load from a CDN).
3. Open documentation/documentation.html for the full setup and
   customization guide — READ THE "Dependencies" SECTION FIRST, this
   template is not fully self-contained like a plain static template.

WHAT'S INSIDE
-------------
- index.html            (the full one-page site)
- css/style.css         (design system — edit the :root variables to re-theme)
- js/main.js            (cursor, preloader, mobile nav, form — degrades
                          gracefully if the CDN libraries below fail to load)
- js/animations.js      (GSAP/ScrollTrigger: scroll reveals, counting stats,
                          pinned work gallery, decode-text, scroll-drawn
                          timeline, and more — see the documentation)
- js/scene.js           (Three.js hero particle field)
- images/favicon.svg
- documentation/documentation.html  (full documentation)
- LICENSE.txt           (included-asset & third-party library licenses)
- CHANGELOG.txt

No build tools or npm install required — just HTML, CSS and JavaScript,
plus two libraries (GSAP and Three.js) loaded via <script> tags from a CDN.
