HALO — Branding & Web Studio Template
=======================================

Thanks for picking up this template!

QUICK START
-----------
1. Unzip this folder.
2. Open index.html in any web browser to preview the site (you'll need
   an internet connection — fonts, GSAP and Three.js load from a CDN).
3. Open documentation/documentation.html for the full setup and
   customization guide — READ THE "Dependencies" SECTION FIRST, this
   template is not fully self-contained like a plain static template.

WHAT'S INTERACTIVE
------------------
- Hero showcase deck: segmented control swaps the featured project; the
  card opens a case study.
- Case study modal: four tabbed panels, prev/next project cycling, and an
  "Inquire" action that carries the project into the contact form.
- Brand Lab: four creative directions x four palettes, rendering a live
  brand preview.
- Selected Work: one-card-at-a-time carousel with prev/next and dots.
- Process: four-step stepper with a deliverables detail panel.
- Contact: scope and timeline chips feeding a project estimator.

The contact form is demo-only as shipped — it validates and shows a toast
but sends nothing. documentation/documentation.html shows how to connect it.

WHAT'S INSIDE
-------------
- index.html            (the full one-page site)
- css/style.css         (design system — edit the :root variables to re-theme)
- js/main.js            (preloader, custom cursor, mobile nav, case-study
                          modal, Brand Lab, process stepper, work carousel,
                          scope estimator, demo form — degrades gracefully
                          if the CDN libraries below fail to load)
- js/animations.js      (GSAP/ScrollTrigger: hero intro and parallax, scroll
                          reveals, counting stats, services spotlight,
                          decode-text pull-quote, footer wordmark — see the
                          documentation)
- js/scene.js           (Three.js hero particle field)
- images/favicon.svg
- documentation/documentation.html  (full documentation)
- LICENSE.txt           (included-asset & third-party library licenses)
- CHANGELOG.txt

No build tools or npm install required — just HTML, CSS and JavaScript,
plus two libraries (GSAP and Three.js) loaded via <script> tags from a CDN.
