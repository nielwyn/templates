Launchly — SaaS Landing Page Template

Thanks for picking up Launchly. This template is built with plain HTML, CSS and JavaScript — no build step, no frameworks, no dependencies to install. Unzip it and open index.html in any browser to get started.

What's included

  • index.html — homepage (hero, features, how it works, stats, testimonials, pricing, FAQ)
  • pricing.html — dedicated pricing page with plan comparison table
  • about.html — company story, values and team section
  • contact.html — contact form and info page
  • 404.html — custom not-found page
  • css/style.css — the entire design system in one file
  • js/main.js — nav menu, FAQ accordion, pricing toggle, testimonial carousel, scroll animations, demo form handling
  • images/favicon.svg — the template's favicon/logo mark
  • documentation/documentation.html — this guide
  • LICENSE.txt, CHANGELOG.txt, README.txt

Getting started

Because there's no build tool, you have two options:

  1. Open directly: double-click index.html — it will open in your default browser.
  2. Serve locally (recommended, so relative paths and future AJAX calls behave like production): 
    # Node / bun
bunx serve .

# or Python
python3 -m http.server 8080
Edit any page with a plain text editor or an IDE like VS Code. No npm install, no compiling — save the file and refresh your browser.

Customization

Colors

Every color is a CSS variable at the top of css/style.css:

:root {
  --color-primary: #2f6b4f;
  --color-accent: #e8b13a;
  --color-ink: #16261f;
}

Change these values once and the whole site — buttons, icons, badges — updates automatically.

Fonts

Headings use Bricolage Grotesque, body text uses Work Sans, both loaded free from Google Fonts in the <head> of each page. To swap fonts, change the Google Fonts <link> tag and the --font-body / --font-display variables in style.css.

Logo & favicon

The logo is the .brand-mark element (a styled "L") plus the "Launchly" text, both inline in the HTML — replace the letter and text with your own, or swap in an <img>. The favicon is images/favicon.svg; replace it with your own SVG or PNG (update the <link rel="icon"> tag if you change the file type).

Content sections

Every section is clearly commented by its id or class (#features, #pricing, #faq, etc.) — duplicate a card/block within a section and edit the text to add more items.

Images

The hero mockup, decorative dividers, trajectory arc and quote marks are built from pure CSS/SVG so the template ships with zero bundled photos — avoiding any image licensing issues. If you'd like to add real photography, use images you own the rights to, or a licensed source such as your own photos or a stock library whose license covers commercial use.

Wiring up forms

The contact and newsletter forms are demo-only: submitting shows a success message via js/main.js but nothing is sent anywhere. To collect real submissions, pick one:

  • Form backend service (easiest): sign up for a service like Formspree or a similar form-endpoint provider, then set the form's action to the endpoint it gives you and remove the data-demo-form attribute, e.g. <form action="https://your-form-endpoint" method="POST">.
  • Static host form handling: if you deploy to a static host that offers built-in form handling, follow that host's documentation for the required form attributes.
  • Your own backend: point action at your API endpoint and handle the POST server-side.

Browser support

Tested in the latest Chrome, Firefox, Safari and Edge. Uses modern but widely supported CSS (Grid, custom properties, backdrop-filter) and vanilla JS (IntersectionObserver). No Internet Explorer support.
