LAUNCHLY — SaaS Landing Page Template
======================================

Thanks for picking up this template!

QUICK START
-----------
1. Unzip this folder.
2. Open index.html in any web browser to preview the site.
3. Open documentation/documentation.html for the full setup and
   customization guide (colors, fonts, images, forms, folder structure).

WHAT'S INSIDE
-------------
- index.html, pricing.html, about.html, contact.html, 404.html
- css/style.css        (all styling — edit the :root variables to re-theme)
- js/main.js           (nav menu, FAQ accordion, pricing toggle, carousel)
- images/favicon.svg   (logo mark / favicon)
- documentation/documentation.html  (full documentation)
- LICENSE.txt          (included-asset licenses & usage terms)
- CHANGELOG.txt

No build tools, no frameworks, no npm install required — just HTML, CSS
and JavaScript you fully own and can edit directly.
